## Premium 和 Tier 1，到底怎么选

其实可以非常直接地拆成两类需求。

### 用户主要在日本、韩国和亚太地区

这种场景优先看 Tier 1 的实际价格和流量。

例如 Tier 1 TINY 只有 **$6.90/月**，而且给到 2000GB Max（IN/OUT）；STARTER 为 $12.90/月、4000GB，MINI 为 $21.90/月、8000GB。对于备份、监控、CI/CD、测试环境、跨区域中继，以及主要服务日本本地用户的站点来说，没必要为了“中国大陆优化”支付 Premium 的额外成本。DMIT 对 Tier 1 的官方定位本身就是亚太、北美及欧洲的通用国际路由。

这里尤其值得注意 T1 的价格梯度：

**T1 TINY $6.90 → STARTER $12.90 → MINI $21.90 → MICRO $32.90**

到了 MICRO，已经是 4 vCore、4GB、80GB SSD 和 16000GB Max（IN/OUT）。如果业务真正吃的是流量，而不是中国大陆方向的网络质量，T1 的规格价格比 Premium 低很多。

### 中国大陆用户是主要访问者

这时候网络路线的优先级会明显上升。

DMIT 当前东京 Premium 采用 CN2 GIA，并把它定位为中国大陆方向的优化网络；官方参考数据是东京到上海约 **28ms 平均延迟、低于 0.1% 平均丢包**，同时明确说明实际结果会受到接入运营商、具体目的地和时段影响。

这里的关键词是“参考”。

不要把 28ms 理解成“所有中国大陆用户永远 28ms”。这只是东京到上海的参考测量。北京、广州、成都、不同电信/联通/移动出口、晚高峰时段，实际结果都可能不同。DMIT 自己也明确做了这个限定。

因此，如果你的日本服务器主要承担中国大陆访问业务，应该优先比较**线路实测**，而不是单纯比较“2 核还是 4 核”。

### 同时服务日本和中国大陆

这是 Premium 最容易体现价值的场景。

比如跨境电商后台、日本站 API、面向日本用户的 SaaS，同时又需要大陆团队稳定访问管理后台。此时日本本地访问和中国大陆访问都重要，线路差异会比多买一两个 vCPU 更值得关注。

DMIT 官方给东京 Premium 推荐的场景包括中国大陆面向的网站和应用、低延迟互动服务、跨境电商及支付平台；Tier 1 则更偏全球内容分发、备份和跨区域大流量传输。

## 便宜的 Tier 1 为什么看起来“流量多得离谱”

因为这两个系列实际上在解决不同问题。

举个最直观的例子：

Premium TINY 是 **$21.90/月 + 500GB/月**。

Tier 1 TINY 是 **$6.90/月 + 2000GB Max（IN/OUT）**。

计算资源完全一样，但 Tier 1 的标称流量是 Premium 的 4 倍，价格却只有约三分之一。

这并不矛盾。Premium 的价格结构很大一部分反映的是网络资源，而 Tier 1 则把成本压在更普通的国际路由上。官方对两者的产品定位就是如此：Premium 使用 CN2 GIA 等中国优化路径，Tier 1 不提供专门的中国大陆优化。

所以不要用“每 GB 多少钱”直接判断两个系列谁更划算。你必须先判断这些流量是不是需要经过中国大陆方向的优化网络。

## 日本服务器租用时，流量比 CPU 更容易买错

很多小型网站刚开始会觉得 500GB 已经非常多。

但如果服务器承担图片、下载、视频、镜像、备份、软件分发或者大量 API 返回数据，流量消耗会比 CPU 增长得快得多。

反过来，如果服务器只是：

* WordPress 或普通企业站；
* 小型 API；
* 监控、DNS、Git、CI/CD；
* 个人开发测试环境；

那么你未必需要上到几十 TB 的 Tier 1 套餐。

更现实的选法是先估算过去 30 天的出站流量，再给自己留出 30%～50% 的增长空间。尤其是 Premium，因为当前套餐的流量额度明显低于同档 Tier 1。

另外，DMIT 当前条款说明，套餐月度带宽额度取决于具体服务；超出之后，系统可以提供重置、暂停或限速等处理方式，同时 Fair Use 条款也保留了限速、调整费用、暂停或终止服务的处理空间。

因此，“高带宽端口”与“每月有多少可用流量”不要混为一谈。

## 一个更实用的选择流程

如果你现在就在准备日本服务器租用，可以按这个顺序判断：

**第一步，看用户在哪里。**

日本本地、韩国、东南亚和全球用户为主，先看 Tier 1；中国大陆用户占比较高，再重点看 Premium。

**第二步，看业务吃什么资源。**

网站和 API 往往先吃流量和网络质量；数据库、编译、渲染等场景才更看重 CPU 和内存。

**第三步，看流量。**

不要只看“1Gbps”。端口速度和月度流量是两回事。尤其 Premium 的部分低配套餐，月度流量并不算大。

**第四步，实际测试。**

正式迁移前，测试中国电信、联通、移动，以及你的实际目标城市。还要测试业务真正使用的端口和第三方服务，而不是只测一次 Ping。

**第五步，再看退款窗口。**

新订单的退款条件有明确时间和流量门槛，尽早测试比买半年后才发现线路不符合需求更省事。
